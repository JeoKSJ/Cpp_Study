## 1. C++는 어떤 언어인가

C++는 C 언어를 기반으로 **객체지향**, **제네릭 프로그래밍**, **저수준 메모리 제어**까지 지원하는 컴파일 언어입니다. 소스코드(`.cpp`)를 컴파일러가 기계어로 번역해서 실행 파일을 만듭니다. 이 과정 때문에 실행 속도가 빠르지만, 문법 오류나 메모리 관리에 조금 더 신경을 써야 합니다.

## 2. 가장 기본적인 프로그램

```cpp
#include <iostream>  // 입출력 기능을 담은 헤더 파일을 가져옴

int main() {
    std::cout << "Hello, C++!" << std::endl;
    return 0;
}
```

하나씩 뜯어보면:

- `#include <iostream>` : 화면 출력(`cout`), 입력(`cin`) 기능이 정의된 표준 라이브러리를 불러옵니다.
- `int main()` : 프로그램이 실행될 때 **가장 먼저 호출되는 함수**입니다. 모든 C++ 프로그램은 반드시 `main` 함수를 가져야 합니다.
- `std::cout << "..."` : 화면에 문자열을 출력합니다. `std`는 표준 라이브러리가 속한 "네임스페이스"이고, `::`는 그 안에 있는 걸 꺼내 쓴다는 뜻입니다.
- `return 0;` : 프로그램이 정상적으로 종료되었음을 운영체제에 알립니다.

> 💡 매번 `std::`를 쓰기 귀찮다면 `using namespace std;`를 선언하고 `cout`처럼 바로 쓸 수도 있지만, 큰 프로젝트에서는 이름 충돌을 막기 위해 `std::`를 명시하는 습관을 들이는 게 좋습니다.

## 3. 변수와 자료형

변수는 데이터를 저장하는 "상자"입니다. C++는 **정적 타입 언어**라서 변수를 선언할 때 타입을 반드시 명시해야 합니다.

```cpp
int age = 25;           // 정수
double height = 178.5;  // 실수 (소수점)
char grade = 'A';       // 문자 하나 (작은따옴표)
bool isStudent = true;  // 참/거짓
std::string name = "Kim"; // 문자열 (여러 문자, <string> 헤더 필요)
```

주요 자료형 요약:

| 타입 | 설명 | 크기(대략) |
|---|---|---|
| `int` | 정수 | 4바이트 |
| `double` | 실수 (기본) | 8바이트 |
| `float` | 실수 (정밀도 낮음) | 4바이트 |
| `char` | 문자 1개 | 1바이트 |
| `bool` | true/false | 1바이트 |
| `std::string` | 문자열 | 가변 |

## 4. 입력과 출력

```cpp
#include <iostream>
#include <string>

int main() {
    std::string name;
    int age;

    std::cout << "이름을 입력하세요: ";
    std::cin >> name;

    std::cout << "나이를 입력하세요: ";
    std::cin >> age;

    std::cout << name << "님은 " << age << "살입니다." << std::endl;
    return 0;
}
```

- `std::cin >> 변수` : 키보드로부터 값을 입력받아 변수에 저장합니다.
- `>>`는 "스트림에서 꺼내온다", `<<`는 "스트림으로 밀어넣는다"고 생각하면 방향이 헷갈리지 않아요.

## 5. 연산자

```cpp
int a = 10, b = 3;

std::cout << a + b << std::endl;  // 13 (덧셈)
std::cout << a - b << std::endl;  // 7  (뺄셈)
std::cout << a * b << std::endl;  // 30 (곱셈)
std::cout << a / b << std::endl;  // 3  (정수 나눗셈 → 소수점 버림!)
std::cout << a % b << std::endl;  // 1  (나머지)
```

⚠️ **주의할 점**: `int / int`는 결과도 `int`입니다. `10 / 3`은 `3.333...`이 아니라 `3`이 나옵니다. 소수점 결과가 필요하면 `double`로 형변환해야 합니다.

```cpp
double result = (double)a / b;  // 3.333...
```

비교 연산자(`==`, `!=`, `<`, `>`, `<=`, `>=`)와 논리 연산자(`&&`, `||`, `!`)도 조건문을 배울 때 함께 쓰이니 미리 눈에 익혀두세요.

## 6. 상수

값이 바뀌면 안 되는 데이터는 `const`로 선언합니다.

```cpp
const double PI = 3.14159;
// PI = 3.0; → 컴파일 에러! const는 재할당 불가
```

## 📌 오늘의 요약

1. C++ 프로그램은 반드시 `main()` 함수에서 시작한다.
2. `#include`로 필요한 라이브러리(헤더)를 가져와야 관련 기능을 쓸 수 있다.
3. 변수는 사용 전에 반드시 **타입을 선언**해야 한다 (`int`, `double`, `char`, `bool`, `string`).
4. 출력은 `std::cout <<`, 입력은 `std::cin >>`을 사용한다.
5. `int` 간 나눗셈은 소수점이 버려진다는 점을 항상 주의한다.
6. 값이 변하지 않아야 하면 `const`를 붙인다.
