## 목표

```cpp
Point a(1, 2);
std::cout << a << std::endl;   // (1, 2) 라고 찍히게 만들기
```

## 질문 1. 왜 클래스 안에 못 만들고 밖에 만드나?

2번에서 `a + b`는 `a.operator+(b)`로 바뀐다고 했죠. **왼쪽 피연산자가 `this`**인 멤버 함수였어요.

그런데 `cout << a`는 **왼쪽이 `cout`**입니다. 멤버 함수로 만들려면 `cout` 클래스 안에 함수를 넣어야 하는데, `cout`은 C++ 표준 라이브러리가 만든 거라 우리가 고칠 수 없어요. 그래서 **클래스 밖의 일반 함수**로 만듭니다. 일반 함수는 왼쪽, 오른쪽 피연산자를 둘 다 매개변수로 받아요.

```cpp
std::cout << a;
// 컴파일러가 이렇게 바꿔서 처리:
operator<<(std::cout, a);     // 왼쪽 → 첫 번째 매개변수, 오른쪽 → 두 번째
```

## 질문 2. 함수를 한 줄씩 읽어보기

```cpp
std::ostream& operator<<(std::ostream& os, const Point& p) {
    os << "(" << p.x << ", " << p.y << ")";
    return os;
}
```

| 부분 | 뜻 |
|---|---|
| `std::ostream& os` | 첫 번째 매개변수. **`cout`이 여기 들어옴.** `ostream`은 `cout`의 타입(출력 스트림)이고, `&`는 3강의 참조라서 복사 없이 진짜 `cout`을 받음 |
| `const Point& p` | 두 번째 매개변수. 출력할 Point 객체를 읽기 전용 참조로 받음 |
| `os << "(" << p.x ...` | **이미 있는 `<<`**(문자열, int용)로 조각조각 출력. 즉 우리 객체 출력을 기존 출력 기능들의 조합으로 풀어 쓴 것 |
| `return os;` | 받은 `cout`을 그대로 돌려줌 |
| 반환 타입 `std::ostream&` | 돌려주는 게 `cout`이라는 표시 |

핵심은 **"`os`가 곧 `cout`"**이라는 거예요. `os`는 그냥 매개변수 이름이라 `out`이든 `o`든 상관없습니다.

## 질문 3. 왜 `os`를 다시 돌려주나? (가장 헷갈리는 부분)

**연쇄 출력** 때문이에요. 이 줄을 보세요.

```cpp
std::cout << a << std::endl;
```

`<<`는 왼쪽부터 차례대로 계산되니까 괄호를 치면 이렇습니다.

```cpp
(std::cout << a) << std::endl;
```

① 먼저 `(cout << a)`가 실행되어 `(1, 2)`가 출력되고, ② 그 **결과값**에 `<< endl`이 이어집니다. 그러려면 ①의 결과가 다시 `cout`이어야 해요. 그래서 함수가 `cout`(=`os`)을 돌려주는 겁니다.

```
cout << a << endl
  └─┬─┘
  (1, 2) 출력 후 cout을 돌려줌
       └──┬──┘
       cout << endl  → 줄바꿈
```

만약 `return os;`를 빼고 `void`로 만들면, 단독 `cout << a;`는 되지만 `cout << a << endl;`은 **에러**가 납니다. 돌려받은 게 없어서 뒤에 이을 게 없기 때문이에요. 우리가 평소 `cout << "a" << x << endl`처럼 줄줄이 쓸 수 있는 것도 모든 `<<`가 `cout`을 돌려주기 때문입니다.

## 한눈에 정리: 흐름 따라가기

```cpp
std::cout << a << std::endl;
```

1. `operator<<(cout, a)` 호출 → `os`는 `cout`, `p`는 `a`
2. 함수 안에서 `(1, 2)`를 출력
3. `return os;` → `cout`이 돌아옴
4. 돌아온 `cout`에 `<< endl` 적용 → 줄바꿈

## 파이썬 비유

파이썬의 `__str__`과 목적이 같아요(`print(a)` 했을 때 어떻게 보일지 정의). 다만 `__str__`은 **문자열을 돌려주는** 함수이고, C++는 **`cout`에 직접 써넣고 `cout`을 돌려주는** 함수라는 점이 달라요.

## 마지막 주의점: private이면?

```cpp
class Point {
private:
    int x, y;    // private이면 밖의 함수가 p.x에 접근 불가 → 에러
};
```

이럴 땐 클래스 안에 `friend std::ostream& operator<<(std::ostream& os, const Point& p);`를 적어서 "이 함수는 내부 접근을 허용한다"고 알려줘야 합니다. 지금은 "x, y를 `public`으로 두면 그냥 된다"만 기억하세요.

## 📌 요약

1. `cout << a`는 왼쪽이 `cout`이라서 멤버 함수가 될 수 없고, **클래스 밖 일반 함수** `operator<<(cout, a)`로 만든다.
2. `os`는 `cout`을 참조로 받은 매개변수이고, 함수 안에서는 기존 `<<`들로 내용을 조각조각 출력한다.
3. `return os;`로 `cout`을 돌려주는 이유는 `cout << a << endl` 같은 **연쇄 출력**이 가능하게 하기 위해서다.
4. `private` 멤버를 출력하려면 `friend` 선언이 필요하다.

---

아래 코드를 직접 쳐서 `return os;`를 지워보세요. `cout << a << endl;`에서 에러가 나는 걸 보면 "돌려주는 이유"가 확실히 와닿아요.

```cpp
#include <iostream>

class Point {
public:
    int x, y;
    Point(int x, int y) : x(x), y(y) {}
};

std::ostream& operator<<(std::ostream& os, const Point& p) {
    os << "(" << p.x << ", " << p.y << ")";
    return os;
}

int main() {
    Point a(1, 2);
    std::cout << a << std::endl;
    return 0;
}
```
