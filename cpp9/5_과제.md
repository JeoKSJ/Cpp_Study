## 과제 1. `operator+`와 `operator==` 추가

### `operator+`: 이미 만드신 `operator-`와 거의 똑같아요

```cpp
Point operator-(const Point& other) const {
    return Point(x - other.x, y - other.y);
}
```

여기서 **기호만 `+`로** 바꾸면 됩니다.

```cpp
Point operator+(const Point& other) const {
    return Point(x + other.x, y + other.y);
}
```

### `operator==`: 반환 타입이 `bool`

"두 점이 같은가?"의 답은 점이 아니라 **참/거짓**이니까, 반환 타입이 `Point`가 아니라 `bool`이에요. x와 y가 **둘 다** 같아야 같은 점이므로 `&&`(그리고)로 묶습니다 (2강에서 배운 논리 연산자).

```cpp
bool operator==(const Point& other) const {
    return x == other.x && y == other.y;
}
```

### 사용해보기

```cpp
Point a(5, 7), b(2, 3), c(5, 7);

cout << (a + b) << endl;        // (7, 10)
cout << (a == c) << endl;       // 1  (true는 1로 출력됨)
cout << (a == b) << endl;       // 0  (false는 0으로 출력됨)
```

`bool`은 `cout`으로 찍으면 `true`/`false`가 아니라 **1/0**으로 나와요. 글자로 보고 싶으면 `if`로 풀어서 쓰면 됩니다.

```cpp
if (a == c) cout << "같은 점" << endl;
```

## 과제 2. `operator*`로 `a * 3`, 그리고 `3 * a`

### 먼저 `a * 3` (멤버 함수로 만들기)

`a * 3`은 왼쪽이 `Point`(this), 오른쪽이 `int`예요. 그래서 매개변수가 `Point`가 아니라 **`int`**입니다. x, y를 각각 3배로 해서 새 점을 돌려줘요.

```cpp
// class Point 안에 추가
Point operator*(int n) const {
    return Point(x * n, y * n);
}
```

```cpp
Point a(5, 7);
cout << (a * 3) << endl;   // (15, 21)
```

`int`는 기본 타입이라 복사 비용이 없어서 `const &` 없이 그냥 받아도 됩니다.

### `3 * a`는 왜 안 될까?

위 함수만으로는 `3 * a`가 **에러**입니다. 이유는 9강 6번에서 본 규칙 때문이에요.

> 멤버 함수는 **왼쪽 피연산자가 그 클래스의 객체**여야 한다

`3 * a`는 왼쪽이 `int`(3)인데, `int` 안에 우리 함수를 넣을 수는 없죠. 그래서 **클래스 밖의 일반 함수**로 만들어야 합니다. `operator<<`를 밖에 만들었던 것과 똑같은 이유예요.

```cpp
// class Point 밖에 추가
Point operator*(int n, const Point& p) {
    return Point(p.x * n, p.y * n);
}
```

일반 함수는 왼쪽, 오른쪽을 둘 다 매개변수로 받으니까, 왼쪽(`int n`), 오른쪽(`const Point& p`) 순서로 적으면 됩니다. 내부 계산은 멤버 버전과 같고, 멤버가 아니라서 `x` 대신 `p.x`로 써야 한다는 점만 달라요.

```
a * 3  →  a.operator*(3)         (멤버 함수가 처리)
3 * a  →  operator*(3, a)        (일반 함수가 처리)
```

## 전체 코드 (그대로 쳐보세요)

```cpp
#include <iostream>
using namespace std;

class Point {
public:
    int x, y;
    Point(int x, int y) : x(x), y(y) {}

    Point operator+(const Point& other) const {
        return Point(x + other.x, y + other.y);
    }

    Point operator-(const Point& other) const {
        return Point(x - other.x, y - other.y);
    }

    bool operator==(const Point& other) const {
        return x == other.x && y == other.y;
    }

    Point operator*(int n) const {        // a * 3
        return Point(x * n, y * n);
    }
};

Point operator*(int n, const Point& p) {  // 3 * a
    return Point(p.x * n, p.y * n);
}

ostream& operator<<(ostream& os, const Point& p) {
    os << "(" << p.x << ", " << p.y << ")";
    return os;
}

int main() {
    Point a(5, 7), b(2, 3), c(5, 7);

    cout << (a + b) << endl;    // (7, 10)
    cout << (a - b) << endl;    // (3, 4)
    cout << (a * 3) << endl;    // (15, 21)
    cout << (3 * a) << endl;    // (15, 21)

    if (a == c) cout << "a와 c는 같은 점" << endl;
    if (!(a == b)) cout << "a와 b는 다른 점" << endl;

    return 0;
}
```

실행하면 이렇게 나와야 해요.

```
(7, 10)
(3, 4)
(15, 21)
(15, 21)
a와 c는 같은 점
a와 b는 다른 점
```

## 확인해볼 만한 실험

1. 일반 함수 `operator*(int, const Point&)`를 **지우고** `cout << (3 * a)`를 실행해보세요. 컴파일 에러가 나는 걸 보면 "왜 밖에 만들어야 하는지"가 확실해져요.
2. `operator==`에서 `&&`를 `||`로 바꾸면 어떻게 달라질지 예상해본 뒤 실행해보세요. (x나 y 중 하나만 같아도 "같은 점"이 됩니다)

## 📌 정리

1. `operator+`는 `operator-`와 구조가 같고 기호만 다르다.
2. `operator==`는 반환 타입이 `bool`이고, 비교할 값들을 `&&`로 묶는다.
3. `a * 3`처럼 왼쪽이 객체면 **멤버 함수**, `3 * a`처럼 왼쪽이 기본 타입이면 **클래스 밖 일반 함수**로 만든다.
