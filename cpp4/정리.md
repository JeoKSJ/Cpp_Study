## 1. 배열(Array)이란?

같은 타입의 데이터 여러 개를 **연속된 메모리 공간**에 나란히 저장하는 자료구조입니다.

```cpp
int scores[5] = {90, 85, 100, 70, 95};

std::cout << scores[0] << std::endl;  // 90 (첫 번째 원소)
std::cout << scores[2] << std::endl;  // 100 (세 번째 원소)
```

- 배열의 **인덱스(index)는 0부터 시작**합니다. `scores[5]`처럼 크기를 벗어난 인덱스에 접근하면 컴파일러가 막아주지 않고 **정의되지 않은 동작(undefined behavior)**이 발생합니다. 이건 C++에서 자주 나오는 버그 원인이니 꼭 기억해두세요.

```cpp
int arr[3];        // 크기만 정하고 초기화 안 함 (쓰레기값 들어있음)
arr[0] = 1;
arr[1] = 2;
arr[2] = 3;
```

배열을 순회할 때는 `for`문을 자주 씁니다.

```cpp
int scores[5] = {90, 85, 100, 70, 95};

for (int i = 0; i < 5; i++) {
    std::cout << scores[i] << " ";
}
```

## 2. 메모리 주소와 & 연산자

모든 변수는 메모리의 어딘가에 저장되어 있고, 그 위치를 **주소(address)**라고 합니다. `&` 연산자로 변수의 주소를 확인할 수 있습니다.

```cpp
int x = 10;
std::cout << x << std::endl;    // 10 (값)
std::cout << &x << std::endl;   // 0x7ffee... (주소, 실행할 때마다 다름)
```

> 💡 3강에서 함수 매개변수에 썼던 `&`(참조)와는 사용 위치가 다르지만 본질적으로 "메모리 주소"와 관련이 있습니다. 뒤에서 자연스럽게 연결해볼게요.

## 3. 포인터(Pointer)란?

**포인터는 "다른 변수의 주소를 저장하는 변수"**입니다. 처음엔 낯설지만, "이 상자엔 값이 아니라 다른 상자의 위치가 적혀있다"고 생각하면 이해가 쉬워요.

```cpp
int x = 10;
int* ptr = &x;   // ptr은 x의 주소를 저장하는 포인터

std::cout << x << std::endl;     // 10        (x의 값)
std::cout << &x << std::endl;    // 0x7ffee.. (x의 주소)
std::cout << ptr << std::endl;   // 0x7ffee.. (ptr에 저장된 값 = x의 주소, 위와 동일)
std::cout << *ptr << std::endl;  // 10        (ptr이 가리키는 곳의 값 = x의 값)
```

핵심 기호 두 가지:

- `int* ptr = &x;` 에서 `*`는 **"포인터를 선언한다"**는 뜻 (이 줄에서만 특별한 의미)
- `*ptr` 은 **"포인터가 가리키는 곳의 값을 꺼내온다"**는 뜻 (역참조, dereference)

헷갈리기 쉬운 부분이라 표로 정리하면:

| 표현 | 의미 |
|---|---|
| `x` | x의 값 |
| `&x` | x의 주소 |
| `ptr` | ptr에 저장된 값 (= x의 주소) |
| `*ptr` | ptr이 가리키는 곳의 값 (= x의 값) |

## 4. 포인터로 값 바꾸기

포인터를 통해 원본 변수의 값을 직접 바꿀 수도 있습니다.

```cpp
int x = 10;
int* ptr = &x;

*ptr = 20;   // ptr이 가리키는 곳(=x)의 값을 20으로 바꿈
std::cout << x << std::endl;  // 20!
```

`*ptr = 20;`은 "ptr이 가리키는 상자에 20을 넣어라"는 뜻입니다. 그 상자가 곧 `x`이므로 `x`도 바뀝니다.

## 5. 함수에서 포인터 사용하기 (3강 복습 연결)

3강에서 배운 참조 전달(`&num`)과 비슷한 일을 포인터로도 할 수 있습니다.

```cpp
void increase(int* num) {
    *num = *num + 1;   // 포인터가 가리키는 값을 바꿈
}

int main() {
    int x = 10;
    increase(&x);    // x의 주소를 넘김
    std::cout << x << std::endl;  // 11
    return 0;
}
```

- `increase(&x)`처럼 함수를 호출할 때 **주소를 넘겨주는 것**을 "포인터에 의한 전달(Pass by Pointer)"이라고 부릅니다.
- 참조(`&num`)와 포인터(`int* num`)는 결과적으로 비슷한 일을 하지만, 참조가 문법이 더 간결해서 C++에서는 참조를 더 자주 씁니다. 포인터는 "가리키는 대상을 나중에 바꿀 수 있다"거나 "아무것도 안 가리킬 수 있다(`nullptr`)"는 특징이 있어 더 유연하지만, 그만큼 실수하기도 쉽습니다.

## 6. 배열과 포인터의 관계

사실 **배열의 이름은 그 배열의 첫 번째 원소를 가리키는 포인터처럼 동작**합니다.

```cpp
int arr[3] = {10, 20, 30};

std::cout << arr << std::endl;     // 배열의 시작 주소
std::cout << &arr[0] << std::endl; // 위와 동일한 주소!
std::cout << *arr << std::endl;    // 10 (첫 번째 원소 값)
```

포인터에 숫자를 더하면 "다음 칸으로 이동"합니다. 이걸 **포인터 연산**이라고 합니다.

```cpp
int arr[3] = {10, 20, 30};
int* p = arr;             // 배열의 시작을 가리킴

std::cout << *p << std::endl;       // 10
std::cout << *(p + 1) << std::endl; // 20 (한 칸 이동)
std::cout << *(p + 2) << std::endl; // 30 (두 칸 이동)
```

`arr[i]`와 `*(arr + i)`는 사실 완전히 같은 표현입니다. 컴파일러가 내부적으로 후자로 바꿔서 처리합니다.

## 7. nullptr

포인터가 아직 아무것도 가리키지 않을 때는 `nullptr`로 초기화하는 게 안전합니다.

```cpp
int* ptr = nullptr;   // 아무 곳도 가리키지 않음

if (ptr == nullptr) {
    std::cout << "아직 아무것도 가리키지 않음" << std::endl;
}
```

⚠️ `nullptr`인 포인터를 역참조(`*ptr`)하면 프로그램이 즉시 강제 종료(crash)됩니다. 포인터를 쓰기 전엔 `nullptr`이 아닌지 확인하는 습관이 중요합니다.

## 📌 오늘의 요약

1. 배열은 같은 타입의 데이터를 연속된 메모리에 저장하며, 인덱스는 0부터 시작한다. 범위를 벗어난 접근은 컴파일러가 막아주지 않는다.
2. `&`는 변수의 주소를 얻고, 포인터는 그 주소를 저장하는 변수다 (`int* ptr = &x;`).
3. `*ptr`은 포인터가 가리키는 곳의 "값"을 의미한다(역참조). 이 값을 바꾸면 원본도 바뀐다.
4. 함수에 `&x`(주소)를 넘기고 매개변수를 포인터(`int*`)로 받으면, 3강의 참조 전달과 비슷하게 원본을 바꿀 수 있다.
5. 배열 이름은 첫 원소를 가리키는 포인터처럼 동작하며, `arr[i]`와 `*(arr + i)`는 같은 의미다.
6. 아무것도 가리키지 않는 포인터는 `nullptr`로 초기화하고, 사용 전 `nullptr` 여부를 확인하는 습관을 들이자.
